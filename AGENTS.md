# Instruções do projeto

- Após concluir qualquer correção ou alteração solicitada, execute as verificações relevantes, faça commit apenas dos arquivos da tarefa e envie o commit para o remoto com `git push`.
- Não deixe mudanças concluídas somente no ambiente local, salvo se o usuário pedir explicitamente para não fazer commit ou push.
- Se uma verificação falhar ou o push estiver bloqueado, informe o problema em vez de publicar uma alteração inválida.
